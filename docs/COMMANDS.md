## 💡 使用技巧

### 1. 快速记账
- 直接发送 `+金额` 即可快速记录入款
- 使用 `+0` 或 `显示账单` 快速查看当前账单

### 2. 汇率和费率
- 可以为每个用户单独设置汇率和费率
- 也可以在每次交易时临时指定汇率和费率
- 优先级：交易指定 > 个人配置 > 群组默认

### 3. 账单管理
- 使用 `撤销入款` 和 `撤销下发` 可以快速撤销最后一条记录
- `保存账单` 会生成每日汇总并标记为已保存
- 定时日切会自动在指定时间生成汇总

### 4. 显示模式
- **纯净模式**：只显示交易基本信息
- **显示回复人**：显示是回复谁的消息进行的操作
- **显示操作人**：显示是谁执行的操作

### 5. 操作权限
- 可以指定特定用户为操作人
- 可以设置全员可操作
- 超级管理员可以设置全局操作人（在所有群组都有权限）

## ⚠️ 注意事项

1. 所有涉及金额的命令都需要操作人权限
2. 某些命令（如上课/下课）需要机器人具有管理员权限
3. 汇率和费率的设置会影响后续所有交易的计算
4. 删除账单操作不可恢复，请谨慎使用
5. 建议定期使用"保存账单"功能备份数据
